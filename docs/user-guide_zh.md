# EggplantShot — 使用指南

macOS 菜单栏截图工具（Snipaste 风格：框选 → 标注 → 钉住 / 复制 / 保存）。

## 权限

| 权限 | 用途 |
|------|------|
| **辅助功能（Accessibility）** | 全局快捷键 |
| **屏幕录制（Screen Recording）** | 截取画面 |

未授权辅助功能时，全局热键无效。未授权屏幕录制时，截取会失败并提示。

## 截取

| 操作 | 默认快捷键 |
|------|------------|
| **截取（Snip）** | `F1` |
| **截取并复制（Snip and copy）** | `⌘F1` |

1. 各显示器画面冻结；鼠标悬停会高亮光标下的窗口。
2. 单击锁定该窗口，或拖拽自由框选区域。
3. 调整蓝色选区（内部拖动平移 / 手柄缩放），按需标注，再点 **钉住（Pin）** / **复制（Copy）** / **保存（Save）**。
4. **Return** 确认主操作（普通截取默认为钉住；截取并复制默认为复制）。**Esc** 取消本次截取。

菜单栏 → **Disable hotkeys** 可暂停全局快捷键（会记住设置）。

## 钉住（Pin）

浮动图片叠在普通窗口之上。拖动可移动。**Esc** 或双击只关闭当前这一枚钉图。

## 标注（精修阶段）

选区下方工具栏：形状、箭头、铅笔、马赛克（模糊）、文字、撤销/重做，以及取消 / 钉住 / 保存 / 复制。

- 标注作用在**整块冻结画面**上，不限于蓝色选区内。钉住 / 复制 / 保存仍按选区裁切（选区外的笔迹不会进成品图）。
- **⌘Z** / **⇧⌘Z**（或 **⌘Y**）撤销 / 重做。**Delete** 删除当前选中的标注。
- 编辑文字时按 **Esc** 只结束编辑；否则 Esc 会取消整次截取。

### 铅笔 — 移动与绘制

铅笔工具激活时，鼠标移到已有铅笔笔迹上**仍保持绘制准星**，方便贴边描画，不会一碰上就变成拖动手势。

若要在不切换工具的情况下**移动**铅笔笔迹：

1. 按住 **⌘**
2. 移到笔迹上 → 出现四向箭头光标
3. 拖动调整位置
4. 松开 **⌘** 继续绘制

（切换到其他标注工具后，直接点铅笔笔迹也可以拖动。）

### 其他常用修饰键

| 场景 | 修饰键 | 效果 |
|------|--------|------|
| 形状 / 马赛克区域 | **Shift** | 正方形 / 正圆 |
| 箭头 / 铅笔 / 自由模糊笔刷 | **Shift** | 直线（箭头另有 45° 吸附） |

## 截取过程中浏览历史

覆盖层打开时，**`,`** 切到更早的截图记录，**`.`** 切到更新的记录（把以往画面与标注带回当前精修会话）。

## 偏好设置

从菜单栏图标打开（**Settings…** / 偏好设置）。平时几乎没有 Dock 图标——本应用以菜单栏为主，仅在打开偏好设置时可能出现 Dock 图标。
