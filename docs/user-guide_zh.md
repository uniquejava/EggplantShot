# EggplantShot — 使用指南

macOS 菜单栏截图工具（Snipaste 风格：框选 → 标注 → 钉住 / **F3 贴图** / 复制 / 保存）。

## 权限

| 权限 | 用途 |
|------|------|
| **辅助功能（Accessibility）** | 全局快捷键 |
| **屏幕录制（Screen Recording）** | 截取画面 |

未授权辅助功能时，全局热键无效。未授权屏幕录制时，截取会失败并提示。

## 截取

| 操作 | 默认快捷键 |
|------|------------|
| **截取（Capture）** | `F1` |
| **截取并复制（Capture and copy）** | `⌘F1` |

**截取：** 各显示器画面冻结；悬停高亮窗口；单击锁定或拖拽框选；调整蓝色选区、按需标注，再点 **钉住** / **复制** / **保存**。**Return** 确认钉住。**Esc** 取消。

**截取并复制：** 同样冻结 + 悬停/拖拽选区；窗口锁定或拖拽结束即裁切并写入剪贴板（不显示工具栏、不可标注）。选区过程中 **Esc** 可取消。

菜单栏 → **Disable hotkeys** 可暂停全局快捷键（会记住设置）。

## 粘贴 / Paste（亮点）

| 操作 | 默认快捷键 |
|------|------------|
| **粘贴（Paste）** | `F3` |

这里的「粘贴」**不是**往 Word / 记事本里粘，而是把剪贴板内容变成屏幕上的**置顶浮动钉图**（Snipaste 同款「贴图」）。

| 剪贴板内容 | 效果 |
|------------|------|
| 图片（例如刚用 **截取并复制** 得到的） | 直接钉成浮动图 |
| 颜色文本 — `#RRGGBB` / `#RGB`，或三个 RGB 数（`0–255` 或 `0–1`） | 色卡贴图（带颜色值文字） |
| 纯文本或 HTML | 渲染成文字便签图 |
| Finder 里复制的**图片文件** | 第一次贴出图像；再按一次 **Paste** → 贴出路径文字 |
| 复制的非图片文件 | 路径渲染成文字图 |

钉图出现在鼠标附近。菜单栏里的 **Paste** 同样可用。截取覆盖层打开时会忽略 Paste。

**推荐用法：** `⌘F1` 框选一块参考图 → `F3` 浮在桌面上对照着改别的窗口；或复制 `#3B82F6` / 一段说明文字 → `F3` 变成色卡或文字便签。

## 钉住（Pin）

浮动图片叠在普通窗口之上。拖动可移动。滚轮缩放 ±10%（左上角短暂显示百分比）。**Esc** 或双击只关闭当前这一枚钉图。**Hide/Show all images**（`⇧F3`）可隐藏或恢复全部钉图。

## 标注（精修阶段）

选区下方工具栏：移动、形状、箭头、铅笔、马克笔、马赛克（模糊 / 像素化）、文字、步骤序号、放大镜、橡皮擦、**识别文字（OCR）**、撤销/重做，以及取消 / 钉住 / 保存 / 复制。

- 标注作用在**整块冻结画面**上，不限于蓝色选区内。钉住 / 复制 / 保存仍按选区裁切（选区外的笔迹不会进成品图）。
- **识别文字**会先尝试识别选区内的**二维码**，否则做 OCR；有结果则写入剪贴板并播放短提示音，然后关闭本次截取（没有结果面板）。
- **⌘Z** / **⇧⌘Z**（或 **⌘Y**）撤销 / 重做。**Delete** 删除当前选中的标注。
- 精修快捷键（选区锁定后；编辑文字时字母键仍用于输入）：**V** 移动 · **A** 箭头 · **S** 形状 · **D** 铅笔 · **F** 马克笔 · **M** 马赛克 · **I** 文字 · **N** 序号 · **E** 橡皮擦 · **P** 钉住 · **O** OCR · **⌘S** 保存 · **⌘C** 复制。**R** / **G** / **B** 切换红 / 绿 / 青（作用于选中标注或当前工具）。
  - ASDF 助记：**A**rrow 箭头 · **S**hape 形状 · **D**raw 铅笔 · **F** 像一把刷子，用来高亮。**I** = Insert（在光标处插入文字）。**V** = 移动 / 选中标注。
- 编辑文字时按 **Esc** 只结束编辑。否则 Esc 依次：取消拖拽 → 卸下工具 → 取消选中标注 → **仍有标注**时先出现轻提示「再按一次放弃」，再按一次才退出。工具栏 **✕** 在存在标注时同样需要点两次确认。

### 移动（V）

按 **V**（或工具栏光标图标）进入移动模式：单击拖动任意标注（含矩形 / 椭圆内部），用手柄缩放。空白处点击取消选中。再按 **V** 或其它工具键退出。（关掉 **V** **不会**变成拖动蓝色选区。）

**按住 Space** 拖动可移动**蓝色选区**（临时手型光标）。松开 Space 回到当前工具。用手柄或从选区外侧扩展可调整裁切大小。

### 绘制工具 — 移动与绘制

铅笔 / 马克笔 / 马赛克 / 橡皮擦以**自由涂抹**（笔刷）模式激活时，悬停在已有标注上**仍保持绘制光标**。要挪位置：按 **V** 进入移动模式拖动，再按回工具键（如 **D**）继续画。

**矩形 / 椭圆区域模式不同。** 高亮、马赛克、橡皮擦的区域标注此时像对象一样：点击它的任意位置（内部或边框）即可拖动，用手柄即可缩放，无需切换工具。笔刷线条仍然穿透绘制。由此带来一点限制：想在已有区域**内部**新建一个区域，需要从它外侧开始拖动（或先按 **Esc** / 用 **V**）。

在对象工具（形状 / 箭头 / 文字 / …）下，绘制类标注仍穿透绘制；其它标注保持点选移动。

**步骤序号**是对象工具里的例外：可在形状 / 箭头等边框上直接盖章。悬停已有序号可移动；按住 **⌘** 可临时移动其它标注。

### 其他常用修饰键

| 场景 | 修饰键 | 效果 |
|------|--------|------|
| 精修（任意工具） | **Space**（按住） | 拖动蓝色选区 |
| 形状 / 马赛克区域 | **Shift** | 正方形 / 正圆 |
| 箭头 / 铅笔 / 自由模糊笔刷 | **Shift** | 直线（箭头另有 45° 吸附） |
| 序号工具悬停在非序号标注上 | **⌘** | 临时移动 |

## 截取过程中浏览历史

覆盖层打开时，**`,`** 切到更早的截图记录，**`.`** 切到更新的记录（把以往画面与标注带回当前精修会话）。

## 偏好设置

从菜单栏图标打开（**Settings…** / 偏好设置）。平时几乎没有 Dock 图标——本应用以菜单栏为主，仅在打开偏好设置时可能出现 Dock 图标。

| 分区 | 内容 |
|------|------|
| **General** | 登录时启动；界面语言（系统 / 英语 / 简体中文；改语言会重启应用） |
| **Permissions** | 辅助功能、屏幕录制状态与授权入口 |
| **Hotkeys** | 自定义截取 / 贴图等快捷键 |
| **About** | 版本与简介 |
