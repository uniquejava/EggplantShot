# 01: 保存对话框被其他应用窗口盖住后，程序像卡死一样无法操作

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

## 问题描述

使用保存截图功能时，弹出的系统「保存」对话框有时会被其他应用的窗口盖住。切换到别的应用、或用 Cmd+Tab 切走之后，尤其容易发生。

## 现象

- 保存对话框被盖住 / 看不见之后，程序像卡死了一样：按任何键都没有反应。
- 此时状态栏（菜单栏）图标的菜单项也全部变灰，无法点击。
- 因为完全没有反应，一度以为程序已经崩溃 / 死掉了。

## 复现步骤

1. 截图后选择「保存」，弹出系统保存对话框。
2. 用 Cmd+Tab 切换到另一个应用（或点击其他应用的窗口）。
3. 保存对话框消失 / 被盖住，之后无法再对本程序进行任何操作。

## 验收标准

- [ ] 保存对话框弹出后，切换到其他应用或 Cmd+Tab 切走时，对话框仍然可见。
- [ ] 对话框始终可操作，程序不会出现按键无反应、像卡死的情况。
